只需几秒即可注册 VectorChord Cloud 并免费开始使用。

如需了解 Cloud 免费套餐包含的内容，请参阅 [Cloud 免费套餐](/zh/cloud/pricing/price-plan/#free-tier)。如需了解 Cloud 的付费套餐选项，请参阅 [Cloud 套餐](/zh/cloud/pricing/price-plan/)。

## 注册 {#sign-up}

注册 VectorChord Cloud 非常简单。只需访问 https://cloud.vectorchord.ai 并使用您的 GitHub 账户注册即可。

![](/cloud/images/signup.png)

完成注册后，系统会将您引导至 VectorChord Cloud 控制台，并为您创建一个默认项目。

![](/cloud/images/after_login_in.png)

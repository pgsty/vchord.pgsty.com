In an exciting development, we are thrilled to announce the launch of [PGVecto.rs](/docs/vectors/) Cloud - bringing the power of scalable vector search to your PostgreSQL databases, now available as a fully managed cloud service.

[PGVecto.rs](/docs/vectors/) is a pioneering Postgres extension that enables high-performance vector search, empowering developers to build advanced similarity-based applications on top of their existing Postgres infrastructure. With [PGVecto.rs](/docs/vectors/) Cloud, you can now unlock the benefits of this transformative technology without the overhead of managing the extension yourself.

![](https://framerusercontent.com/images/HgBD4Sp9X3rig7dK1MYFxXSKh7I.png?scale-down-to=2048)

By seamlessly integrating with your existing Postgres infrastructure, [PGVecto.rs](/docs/vectors/) Cloud empowers you to build cutting-edge applications that can:

1. **Revolutionize Search**: Unlock the true potential of your data with the ability to perform scalable, high-performance vector search, empowering your users to find the most relevant and similar results.
    
2. **Enhance Filtering**: Apply any filter conditions and join with other tables, achieving high recall and low latency, a distinctive edge over other vector databases.
    
3. **Leverage Extended Vector Length**: [PGVecto.rs](/docs/vectors/) Cloud supports vector lengths up to 65,535, making it capable of handling the latest machine learning models and their ever-increasing output dimensionality.
    
4. **Optimize Binary Vector Search**: Utilizing adaptive retrieval techniques, [PGVecto.rs](/docs/vectors/) Cloud can maintain a high level of accuracy while significantly reducing memory usage by up to 30 times.
    
5. **Seamlessly Combine Text and Vector Search**: Leverage the full-text search functionality in Postgres with [PGVecto.rs](/docs/vectors/) Cloud to search text and vector data within a single query, unlocking unprecedented flexibility and power.
    
6. **Enjoy Unparalleled Performance**: Boasting a speed that is 4x faster than other Postgres-based solutions, [PGVecto.rs](/docs/vectors/) Cloud delivers lightning-fast response times, ensuring your applications stay lightning-fast.
    
7. **Embrace Complete SQL Support**: [PGVecto.rs](/docs/vectors/) Cloud offers full SQL support, enabling seamless integration with your existing workflows and allowing you to leverage joins, filters, and other SQL features without limitations or extra configuration.
